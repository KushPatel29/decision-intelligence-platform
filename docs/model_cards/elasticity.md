# Price elasticity

_Generated by `scripts/build_model_cards.py` from the latest pipeline run._

## Purpose

Demand response to the effective price, by zone, travel period and customer segment.

## Method

Log-log OLS per cell with weather and calendar controls on randomised daily price tests, shrunk toward the period x segment mean by empirical Bayes.

## Evidence (simulation check)

| Method | RMSE vs true elasticity |
|---|---|
| Empirical Bayes (serving) | 0.052 |
| Cell OLS | 0.043 |
| Pooled by period x segment | 0.181 |
| Monotone gradient boosting | 0.652 |

95% intervals contain the true elasticity in 94% of cells. Gradient boosting predicts demand comparably (MAE 5.27 vs 5.11) yet recovers the price response worst.

## Limits

Constant elasticity within the tested -30% to +10% range; illustrative effective prices.
